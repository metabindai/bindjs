# Contributing

- Editorial fixes, examples, and clarifications: open a pull request.
- Changes to the specification, a binding, or the conformance surface: open a BEP under [`proposals/`](proposals/) (see [BEP-0001](proposals/BEP-0001-process.md)). The BEP and the specification text change in the same pull request.
- Adding an implementation: add a row to [`registry/renderers.md`](registry/renderers.md) and a statement under [`conformance/statements/`](conformance/statements/) with a `conformance.json` in your repository.
- Style: normative language uses MUST, SHOULD, and MAY (RFC 2119). Lists that define conformance (Core components, Core modifiers, hooks, environment keys) are generated by the conformance test, not typed by hand.
